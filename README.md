# Tesla Financial Analytics Dashboard
Tesla-nın maliyyə göstəricilərini və səhmlərinin tarixi performansını analiz etmək üçün hazırlanmış Power BI layihəsidir.

Görülən işlər:

Excel məlumatlarının Power Query ilə təmizlənməsi və transformasiyası

Financial, Balance Sheet və Cash Flow məlumatlarının hazırlanması

Calendar table və data relationships yaradılması

DAX ilə əsas maliyyə KPI-larının hesablanması

Revenue, EBITDA, Net Income, Free Cash Flow, Operating Cash Flow, Total Assets və Debt kimi göstəricilərin analizi

İllər üzrə maliyyə performansının və səhm qiymətinin vizuallaşdırılması
İnteraktiv və professional Power BI dashboard hazırlanması

Tools: Power BI, Power Query, DAX, Excel
